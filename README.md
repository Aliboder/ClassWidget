# 课表组件（ClassWidget）

把课表变成 Android 桌面小组件的一个小 App。

导入教务系统导出的 ICS 文件，桌面上就能直接看到今天上什么课、还有多久下课，
不用每次打开课表、翻到当天。

- **只支持 Android**（依赖 App Widget，iOS 没有对应能力）
- 体积极小，约 180 KB，零第三方依赖
- 不申请多余权限（只有「网络」，用于配对码导入）

## 功能

### 桌面小组件

- 显示今天的课：时间、课名、地点、教师
- 进行中的课有进度条，右上角显示「距下课 X 分钟」/「距下节课 X 分钟」
- 可选「显示未来课程」：今天排不满就往后接明天、后天
- 尺寸自适应：2×2 / 4×2 / 4×4 / 平板都排得下，字号跟着格子高度分级
- 地点、教师图标跟着字号缩放，平板上不会缩成小点

### App 内时间线

- 按天分组的课程卡片，样式对齐配套小程序的时间线视图
- 今天那一段高亮，并在「已经上完」和「还没上」之间插一条「现在」标线
- 「过去 N 天」可展开 / 收起，默认只渲染今天及以后

### 样式编辑

- 6 个无级滑杆：背景透明度、卡片透明度、字号、卡片高度、卡片圆角、背景圆角
- 4 套快捷预设：默认 / 玻璃 / 极简 / 高对比
- 地点、教师、显示未来课程、点击行为、刷新频率，全部可开关
- 改完即时生效，桌面组件同步刷新

### 导入方式

1. **配对码**（推荐）：在配套小程序「导出日历 → 生成配对码」拿到 6 位数字，
   在 App 里输入即可。App 会自动读剪贴板，小程序点一下码就不用再手输。
2. **本机 ICS 文件**：从文件管理器选，或从微信里「其他应用打开」。

## 安装

下载最新的 APK 直接安装。首次安装需要在系统设置里允许「安装未知来源应用」。

装好后：

1. 长按桌面空白处 →「小组件」→ 找到「课表组件」→ 拖到桌面
2. 打开 App，导入课表
3. 长按组件可以拉伸尺寸（4×2 显示 2 条，4×4 显示 5 条）

## 使用说明

### 配对码导入

配套小程序「周程 → 导出日历 → 生成配对码」会给出 6 位数字（5 分钟内有效，取走即失效）。
点一下码即复制，回到本 App 点「输入配对码」，会自动填入，确认后点「获取课表」。

### 直接导入

把 ICS 文件发到手机，用文件管理器打开，或从微信里选「其他应用打开 → 课表组件」。
App 会解析全部日程并保存到本机。

### 样式调节

首页 →「编辑样式」。顶部是实时预览，下面是分区设置。
每改一项，桌面上的组件会立刻刷新。

## 从源码构建

需要 JDK 17 和 Android SDK（compileSdk 36）。

```sh
./gradlew assembleDebug
```

产物在 `app/build/outputs/apk/debug/classwidget-<versionCode>-debug.apk`。

### 版本号规则

```
versionCode = YYMMDD × 100 + 当天序号
```

例如 2026-11-10 第 1 版是 `26111001`。同一天再发一版：

```sh
./gradlew assembleDebug -PbuildSeq=2
```

日期在涨所以 versionCode 天然递增 —— 这对覆盖安装是必须的（不涨的话部分 ROM 会拒绝安装）。

## 技术说明

- 原生 Android，无第三方依赖，minSdk 24 / targetSdk 34
- 桌面组件用 `RemoteViews`，受限于它只能用 `TextView` / `ImageView` 这类基础控件
- 圆角 + 透明度的实现方式：外层 `FrameLayout` 用 `clipToOutline` 裁剪，内层容器
  `setBackgroundColor` 带 alpha —— 因为 `RemoteViews` 不能在运行时改形状 drawable 的圆角和透明度
- 组件刷新用 `AlarmManager` 精确定时：上下课、零点各一次；「智能」模式下有课进行中时每分钟刷一次
- 课程颜色由课名哈希决定（和小程序同一套算法），同一门课在两个端颜色一致
- ICS 解析自己写的：处理折行展开、`TZID` / `Z` 时间、`RRULE WEEKLY` 重复、`EXDATE` 排除，
  并跳过 `VALARM` 等嵌套子块（这是个容易踩的坑：嵌套块里的 `DESCRIPTION` 会盖掉正文）

个人自用工具，非官方。课表数据只存在手机本地，不上传服务器
